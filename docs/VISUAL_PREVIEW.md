## Color/material legend
- **Primary cloth:** matte black (~RGB 15-20), subtle hex normal map.
- **Armor plates:** dark charcoal (~RGB 8-10), semi-gloss with micro-scratches.
- **Accent stitching:** deep cobalt (~RGB 35-45, 60-70, 90-110) around seams and belt edges.
- **Visor/glass:** low-roughness with faint blue tint.

## Download & installation
Follow these steps once your mod package (Data folder) is ready or downloaded:

1. **Get the archive**
   - If using this repository: click **Code → Download ZIP** to fetch the documentation and the `Data` layout if included.
   - If you export your built assets: zip the `Data` folder that contains `Meshes/Textures/Materials` and your plugin (`.esp` or `.esl`).
2. **Install with Nexus Mod Manager (NMM)**
   - Open NMM and click **Add mod from file**.
   - Select your zipped archive. NMM will import it and list it under **Mods**.
   - Click **Activate**. Ensure the plugin (e.g., `MidnightGuardian.esp`) is enabled in the **Plugins** tab.
3. **Manual install option**
   - Extract the archive into your `Fallout 4/Data/` directory, preserving folders: `Meshes/`, `Textures/`, `Materials/`, and the plugin file.
   - Enable the plugin in your mod manager or the game’s load order menu.
4. **Uninstall**
   - In NMM, deactivate and remove the mod. For manual installs, delete the added `MidnightGuardian` folders and the plugin file from `Data/`.

## Where to find it in-game
- Chemistry Station → **Guardian Gear** category (as described in the plugin setup) to craft the armour.
- Suggested recipe: 4x Adhesive, 6x Ballistic Fiber, 6x Leather, 2x Aluminum (tune to your balancing needs) with optional Armorer rank 2 requirement.
